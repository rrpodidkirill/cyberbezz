# 🛡️ Практическое руководство по безопасности компьютера

## 📌 О проекте

Этот проект - практическое руководство для людей с начальным уровнем цифровой грамотности,
которые хотят защитить себя, свои данные и компьютер от вирусов и интернет-мошенников.
